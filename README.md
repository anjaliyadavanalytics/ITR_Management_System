
# ITR Management Analysis Dashboard

## Project Overview

This project analyzes Income Tax Return (ITR) data to understand filing patterns, taxpayer information, income trends, tax-related metrics, and overall return statistics. The dashboard provides interactive insights to support data-driven analysis and reporting.

---

## Objective

- Analyze overall ITR filing patterns
- Understand income and tax trends
- Analyze taxpayer and return-related information
- Identify important patterns and trends
- Create interactive dashboards and visualizations
- Generate meaningful business and analytical insights

---

## Tools & Technologies Used

- Power BI
- DAX
- Power Query
- Excel
- Data Cleaning
- Data Visualization

---

## Key Analysis

- Total ITR Filings
- Total Income
- Total Tax
- Taxpayer Analysis
- Filing Trends
- Income Distribution
- Tax Distribution
- Year-wise Analysis
- Category-wise Analysis

---

## Key Insights

- Analyzed ITR filing trends across different periods
- Identified patterns in income and tax values
- Compared taxpayer categories
- Examined overall filing and tax-related metrics
- Created interactive visualizations for better decision-making
